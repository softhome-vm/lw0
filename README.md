# lw0 — Git и GitHub

Вводная лабораторная **до PHP**: отработка работы с репозиторием, коммитами и удалённым origin.

## Что внутри

- `file1.txt`, `file2.txt`, `file3.txt` — текстовые файлы для правок и фиксации в истории Git.
- История коммитов оформлена по пунктам задания (`пункт_3`, `пункт_4`, …).

## Зачем

Освоить базовые команды Git (init, add, commit, push, pull, merge) на простых файлах, без кода.
